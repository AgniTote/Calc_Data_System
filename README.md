# Calc Data System

**Calc Data System** — проект системы управленческого учёта на базе Excel и Access, дополняющей 1С. Система объединяет данные бухгалтерского учёта и дополнительную детализацию, выполняет расчёты и формирует отчёты.

## Основная идея

Первичные документы вводятся в 1С. Данные из стандартных форм вручную переносятся в Excel, проверяются и сохраняются в общей базе Access. Дополнительные сведения, например рейсы и маршруты, поступают через отдельные файлы ввода.

Excel-файлы выполняют три роли:

- **Ввод** — приём, нормализация и отправка исходных данных.
- **Расчёт** — зарплата, налоги, амортизация, списание материалов и другие показатели с сохранением результатов.
- **Отчёт** — просмотр, печать и выгрузка готовых данных.

Общее хранилище состоит из двух файлов: `Учет.accdb` для рабочих данных и `ИсторияИсправлений.accdb` для истории исправлений. Предусмотрены транзакции, контроль конкурентных изменений, проверка версий файлов, уведомления о зависимых результатах и ограничения периодов редактирования.

## Технологии

Описанная в документации архитектура:

| Компонент | Назначение |
|---|---|
| Microsoft Excel 2016, формулы и VBA | Интерфейс, проверки и экономические расчёты |
| Microsoft Access / ACE, формат `.accdb` | Общее файловое хранилище и ограничения целостности |
| DAO с поздним связыванием | Транзакционная запись и подключение из VBA |
| Power Query | Чтение данных для расчётов и отчётов |
| 1С | Источник бухгалтерских данных и ручной приём отдельных итогов |

Базы размещаются на общем файловом сервере. Предусмотрена работа с 32- и 64-битным Office. Конкретные требования к драйверам и подключениям описаны в технических протоколах.
